# SalesSavvy - Full Stack E-Commerce Platform

![Java](https://img.shields.io/badge/Java-17-orange) ![Spring Boot](https://img.shields.io/badge/Spring%20Boot-3.4.1-brightgreen) ![React](https://img.shields.io/badge/React-18-blue) ![MySQL](https://img.shields.io/badge/MySQL-Database-blue)

A modern full-stack e-commerce application built to deliver a smooth shopping experience for customers and a practical management interface for admins.

## 🚀 Live Demo

Check out the deployed project here: [SalesSavvy - E-commerce](https://e-commerce-java-full-stack-project-zeta.vercel.app/customerhome)

## 📌 Project Overview

SalesSavvy is a complete e-commerce web application developed using Java Spring Boot for the backend and React for the frontend. The project demonstrates core full-stack development skills, including REST API development, database integration, authentication, secure user flows, and responsive UI/UX design.

This project was built as a capstone-style portfolio application to showcase real-world development practices in a modern web application environment.

## ✨ Features

- User registration and login
- Secure authentication with JWT
- OTP-based email verification
- Forgot password functionality
- Product browsing with category-based navigation
- Shopping cart management
- Order placement and order tracking
- Admin dashboard for product and order management
- Responsive and modern interface

## 🛠️ Tech Stack

## ▶️ Getting Started

### Prerequisites
- Java 17+
- Maven
- Node.js and npm
- MySQL

### Backend Setup
```bash
cd backend
mvn spring-boot:run
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
