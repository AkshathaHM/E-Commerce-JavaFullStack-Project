# Frontend - SalesSavvy

This frontend part of the SalesSavvy e-commerce platform is built with React and Vite to provide a fast, modern, and responsive user experience.

## Overview

The frontend includes customer-facing pages such as home, product listing, cart, orders, and authentication flows, along with an admin interface for managing products and store operations.

## Key Features

- Modern and responsive UI
- Dynamic product browsing
- Shopping cart experience
- Secure login and registration flow
- Order tracking and user account pages
- Admin dashboard for management tasks

## Tech Stack

- React.js
- Vite
- React Router DOM
- Axios
- Tailwind CSS / Custom CSS

## Getting Started

### Install dependencies
```bash
npm install
```

### Run locally
```bash
npm run dev
```

### Build for production
```bash
npm run build
```

## Project Purpose

This frontend layer is designed to deliver a smooth and engaging shopping experience while communicating efficiently with the Spring Boot backend APIs.
